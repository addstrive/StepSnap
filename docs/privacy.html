StepSnap Privacy Policy

Last updated: October 17, 2026

StepSnap processes everything locally in your browser. No data is ever sent to any server, third party, or external service.

What StepSnap Records

When you start a recording session, StepSnap captures the following on your device only:

  • Screenshots of your screen (taken after each interaction)
  • Descriptions of your actions (e.g., "Clicked button: Submit", "Typed in Search field")
  • Page titles and URLs of the pages you visit during recording
  • The first 60 characters of text you type into form fields (password fields are never recorded). Turn on "Leave typed text out of guides" in the popup to record only the field name.

Where Data Is Stored

All recorded data is stored exclusively in chrome.storage.local, a sandboxed storage area on your own device managed by Chrome. This data is:

  • Never transmitted to any server or external destination
  • Never shared with third parties
  • Automatically cleared when you start a new recording session
  • Accessible only to the StepSnap extension itself

Permissions Explained

StepSnap requests the following Chrome permissions:

  • activeTab / tabs / scripting / host_permissions (<all_urls>): Required to inject the action-capture script into whichever browser tabs are open when you start recording. Without this, the extension could only record the single tab that was active when you clicked Start. The page script is present on every site so it is ready when you press record; when you are not recording, it ignores clicks and typing entirely and nothing is stored.
  • desktopCapture: Required to take a screenshot after each recorded action, from the screen or window you choose to share in Chrome's screen-share prompt. Screenshots are encoded locally and stored only in chrome.storage.local.
  • storage: Required to save your recorded steps and extension state between the recording session and guide viewer.

Password Fields

StepSnap explicitly skips password fields. When a password input is detected, the extension records only the field label (e.g., "Typed in password field: Password"), never the value entered.

Data Retention

Recorded steps persist in chrome.storage.local until you start a new recording or uninstall the extension. Uninstalling StepSnap removes all locally stored data.

Children's Privacy

StepSnap is not directed at children under 13. No personal information is collected from any user.

Changes to This Policy

If this policy is updated, the "Last updated" date above will change. Material changes will also be noted in the Chrome Web Store listing.
